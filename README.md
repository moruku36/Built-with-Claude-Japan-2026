## 応募アイデア10選（既存アセット: `github.com/moruku36` 活用）

### カテゴリA：専門知見・現場のペインから紡ぎ出すツール

#### 1. ひとり情シス・中小企業向け「対話型セキュリティ監査＆IaC自動修正エージェント」
* **ベース実績:** `personal-security-auditor` / `enterprise-sec-distillation`
* **概要:** セキュリティ専任者がいない開発現場向けに、クラウド設定やTerraform/CloudFormationコードを読み込ませると、エンタープライズ水準の監査から「修正済みPRの作成」までを一気通貫で自動化するツール。

#### 2. ソースコードの「PQC（耐量子暗号）移行インベントリ自動診断＆リファクタリングツール」
* **ベース実績:** `pqc-crypto-inventory-lab`
* **概要:** リポジトリ内に潜む旧来の暗号アルゴリズム（RSA/ECC等）や依存ライブラリを横断特定し、PQC対応に向けた影響範囲の可視化と移行用コード差分を自動生成するツール。

#### 3. 自律型マルチAI開発の「AI PMO・セキュリティ検証ゲートウェイ」
* **ベース実績:** `ai-engineering-factory` / `web-security-control-lab`
* **概要:** 複数のAIエージェントが生成したコードに対し、セキュリティポリシー違反や設計逸脱がないかを独立検証し、自動で差し戻しと修正指示を回す「AIのためのPMOダッシュボード」。

#### 4. サプライチェーン取引先向け「セキュリティチェックシート自動回答＆証跡マッピングAI」
* **ベース実績:** `nedo-supply-chain-data-challenge` / エンタープライズセキュリティ知見
* **概要:** 開発現場で膨大な工数を奪っている「取引先ごとのExcelセキュリティ調査票」に対し、自社の構成コード（IaC）や社内規程を根拠として自動で回答と証跡リンクを埋める業務ペイン解消ツール。

#### 5. ベテランの暗黙知を再現する「インフラ障害切り分け＆ランブック自動実行コパイロット」
* **ベース実績:** `local-ai-sidekick` / インフラ・ネットワーク運用知見
* **概要:** 熟練エンジニアの頭の中にある「障害時のログ確認順序・切り分け思考」を構造化し、アラート発報時に調査コマンドの提案から原因特定までをリアルタイムに伴走するトラブルシューティング支援ツール。

### カテゴリB：専門性の壁を壊す・日本の社会課題を解決するツール

#### 6. 高齢者と家族を守る「メッセンジャー詐欺・フィッシング防衛ヒューマンファイアウォール」
* **ベース実績:** `messenger-human-firewall` / `personal-voice-copilot`
* **概要:** メッセージや通話の文脈から特殊詐欺・フィッシングの兆候をリアルタイム検知し、高齢者本人には分かりやすい音声・画面で警告しつつ、離れて暮らす家族へ安全確認の通知を飛ばす防衛ツール。

#### 7. 介護・自治体現場の人手不足を救う「音声雑談からの公的書類・ケア記録自動生成ツール」
* **ベース実績:** `personal-voice-copilot`
* **概要:** 介護スタッフや高齢者がスマホに向かって「話すだけ」で、複雑な行政申請フォーマットや日々のケア記録へ自動変換・記載漏れチェックまで完了させる現場支援アプリ。

#### 8. 紙の帳票を撮るだけで業務システム化する「現場DX即時アプリジェネレーター」
* **ベース実績:** `qwen-multimodal` / `ai-engineering-factory`
* **概要:** IT人材がいない町工場・建設・飲食などの現場で、紙の点検表や手書きメモをスマホで撮影するだけで、裏側でClaude CodeがWebアプリとDBを即時ビルド・デプロイして使えるようにする民主化ツール。

#### 9. 職人技・シニアの知恵を次世代に残す「対話型デジタル技術継承＆アーカイブ生成アプリ」
* **ベース実績:** `date-memory` / `personal-voice-copilot` / `jev-learning-quest`
* **概要:** AIがインタビュアーとなって熟練職人や高齢者と音声対話し、言語化されていなかった「コツ・手順・記憶」を構造化されたマニュアルや学習クエストとして自動編纂するツール。

#### 10. 高齢者や要配慮者の避難の壁をなくす「パーソナライズ防災・避難ルート対話シミュレーター」
* **ベース実績:** GIS・ハザードマップ連携 / Webフロントエンド実装
* **概要:** 難解な自治体のハザードマップや防災データを統合し、家族構成（高齢の親・徒歩移動の制約など）と現在地を入れるだけで「いつ・どのルートで・どこへ逃げるべきか」を直感的にナビゲートする防災ツール。
